# External validation notes

- Official Trivy Action repository: https://github.com/aquasecurity/trivy-action
- Its current README documents `aquasecurity/trivy-action@v0.36.0` as the working action reference and supports image scans with `image-ref`, `severity`, `exit-code`, and `ignore-unfixed`.
- The previously attempted `0.28.0` and `v0.74.0` references were not resolvable by the repository's GitHub Actions runner; the workflow was corrected to the documented `v0.36.0` tag.
